## [0.1.0] - 2026-10-22

### Added

- Initial release.
- `ghattach upload` sends local files to GitHub user attachments and prints URLs or Markdown embeds.
- `ghattach login` reads a Chrome session on macOS or accepts a cookie from standard input; `logout` removes the stored session.
- Offline examples and synthetic upload tests.
- Release archives for Linux, macOS and Windows, with checksums and a public-release attestation workflow.
